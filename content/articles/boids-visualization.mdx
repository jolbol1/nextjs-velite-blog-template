## What Are Boids?

Boids (bird-oids) is an artificial life simulation originally developed by Craig Reynolds in 1986. The algorithm simulates the flocking behavior of birds using simple rules applied to individual agents (boids). Despite the simplicity of these rules, they produce complex emergent behavior that closely resembles real bird flocks.

The beauty of boids is that there's no central coordination - each boid makes its own decisions based on local information about its neighbors. Yet, when combined, these individual decisions create cohesive group behavior.

## The Core Rules of Boids

The classic boids algorithm is based on three primary rules:

1. **Separation**: Avoid crowding neighbors (short-range repulsion)
2. **Alignment**: Steer towards the average heading of neighbors
3. **Cohesion**: Steer towards the average position of neighbors

In our enhanced implementation, we've added several additional behaviors:

4. **Edge Avoidance**: Steer away from the container edges
5. **Shape Formation**: Attraction to predefined or dynamically generated shapes
6. **3D Depth Perception**: Giving the 2D canvas a sense of 3D space

### Spatial Partitioning for Performance

A key challenge with boid simulations is performance. Naively, each boid would need to check its relationship with every other boid, resulting in O(n²) complexity - too slow for real-time animation with hundreds of boids.

To solve this, we implemented a spatial partitioning grid that divides the space into cells. Boids only need to check neighboring cells, dramatically reducing the number of calculations:

```typescript
class SpatialGrid3D {
  cells: Map<string, Cell>;
  cellSize: number;

  constructor(cellSize: number) {
    this.cells = new Map();
    this.cellSize = cellSize;
  }

  getCellCoords(x: number, y: number, z: number) {
    return {
      row: Math.floor(y / this.cellSize),
      col: Math.floor(x / this.cellSize),
      depth: Math.floor(z / this.cellSize)
    };
  }
  
  getCellKey(row: number, col: number, depth: number): string {
    return `${row},${col},${depth}`;
  }

  addBoid(boid: Boid) {
    const { row, col, depth } = this.getCellCoords(
      boid.position.x, 
      boid.position.y, 
      boid.position.z
    );
    const key = this.getCellKey(row, col, depth);
    
    if (!this.cells.has(key)) {
      this.cells.set(key, { boids: [] });
    }
    
    this.cells.get(key)!.boids.push(boid);
  }

  getNeighbors(boid: Boid, radius: number): Boid[] {
    const neighbors: Boid[] = [];
    const { row, col, depth } = this.getCellCoords(
      boid.position.x, 
      boid.position.y, 
      boid.position.z
    );
    
    // Calculate cell range to check based on radius
    const cellRadius = Math.ceil(radius / this.cellSize);
    
    // Check neighboring cells
    for (let r = row - cellRadius; r <= row + cellRadius; r++) {
      for (let c = col - cellRadius; c <= col + cellRadius; c++) {
        for (let d = depth - cellRadius; d <= depth + cellRadius; d++) {
          const key = this.getCellKey(r, c, d);
          const cell = this.cells.get(key);
          
          if (cell) {
            neighbors.push(...cell.boids);
          }
        }
      }
    }
    
    return neighbors;
  }
}
```

This optimization allows us to simulate thousands of boids in real-time, even on modest hardware.

### The Core Boid Update Logic

The heart of our simulation is the update function that calculates new forces and positions for each boid:

```typescript
const updateBoids = () => {
  const grid = new SpatialGrid3D(perceptionRadius);
  
  // Add boids to spatial grid
  for (const boid of boidsRef.current) {
    grid.addBoid(boid);
  }
  
  // Update each boid
  for (const boid of boidsRef.current) {
    // Find neighbors within perception radius
    const neighbors = grid.getNeighbors(boid, perceptionRadius);
    
    // Apply separation, alignment, cohesion, edge avoidance, and shape formation
    let alignmentForce = { x: 0, y: 0, z: 0 };
    let cohesionForce = { x: 0, y: 0, z: 0 };
    let separationForce = { x: 0, y: 0, z: 0 };
    
    // Count valid neighbors (excluding self)
    let alignmentCount = 0;
    let cohesionCount = 0;
    let separationCount = 0;
    
    // Process neighbors
    for (const neighbor of neighbors) {
      // Skip self
      if (neighbor.id === boid.id) continue;
      
      // Calculate distance to neighbor
      const dx = neighbor.position.x - boid.position.x;
      const dy = neighbor.position.y - boid.position.y;
      const dz = neighbor.position.z - boid.position.z;
      const distSq = dx * dx + dy * dy + dz * dz;
      const dist = Math.sqrt(distSq);
      
      // Apply separation (avoid collision)
      if (dist < separationRadius) {
        // Calculate force away from neighbor
        const force = {
          x: -dx / dist,
          y: -dy / dist,
          z: -dz / dist
        };
        
        // Weight by distance (closer neighbors have stronger effect)
        separationForce.x += force.x / dist;
        separationForce.y += force.y / dist;
        separationForce.z += force.z / dist;
        separationCount++;
      }
      
      // Apply alignment and cohesion if within perception radius
      if (dist < perceptionRadius) {
        // Alignment: match velocity
        alignmentForce.x += neighbor.velocity.x;
        alignmentForce.y += neighbor.velocity.y;
        alignmentForce.z += neighbor.velocity.z;
        alignmentCount++;
        
        // Cohesion: move toward center of mass
        cohesionForce.x += neighbor.position.x;
        cohesionForce.y += neighbor.position.y;
        cohesionForce.z += neighbor.position.z;
        cohesionCount++;
      }
    }
    
    // Calculate final forces
    let alignment = { x: 0, y: 0, z: 0 };
    let cohesion = { x: 0, y: 0, z: 0 };
    let separation = { x: 0, y: 0, z: 0 };
    
    // Alignment: average and normalize
    if (alignmentCount > 0) {
      alignment = normalize({
        x: alignmentForce.x / alignmentCount,
        y: alignmentForce.y / alignmentCount,
        z: alignmentForce.z / alignmentCount
      }, currentMaxSpeed);
    }
    
    // Cohesion: move toward center of mass
    if (cohesionCount > 0) {
      // Calculate center of mass
      const centerOfMass = {
        x: cohesionForce.x / cohesionCount,
        y: cohesionForce.y / cohesionCount,
        z: cohesionForce.z / cohesionCount
      };
      
      // Calculate direction to center of mass
      const toCenterOfMass = {
        x: centerOfMass.x - boid.position.x,
        y: centerOfMass.y - boid.position.y,
        z: centerOfMass.z - boid.position.z
      };
      
      // Normalize and scale
      cohesion = normalize(toCenterOfMass, currentMaxSpeed);
    }
    
    // Separation: normalize
    if (separationCount > 0) {
      separation = normalize({
        x: separationForce.x / separationCount,
        y: separationForce.y / separationCount,
        z: separationForce.z / separationCount
      }, currentMaxSpeed);
    }
    
    // Edge avoidance
    const edgeForce = calculateEdgeAvoidance(boid);
    
    // Shape formation force (if applicable)
    const shapeForce = calculateShapeForce(boid);
    
    // Combine all forces with respective weights
    boid.acceleration.x = 
      alignment.x * alignmentWeight +
      cohesion.x * cohesionWeight +
      separation.x * separationWeight +
      edgeForce.x * edgeAvoidanceWeight +
      shapeForce.x * shapeFormationWeight;
      
    boid.acceleration.y = 
      alignment.y * alignmentWeight +
      cohesion.y * cohesionWeight +
      separation.y * separationWeight +
      edgeForce.y * edgeAvoidanceWeight +
      shapeForce.y * shapeFormationWeight;
      
    boid.acceleration.z = 
      alignment.z * alignmentWeight +
      cohesion.z * cohesionWeight +
      separation.z * separationWeight +
      edgeForce.z * edgeAvoidanceWeight +
      shapeForce.z * shapeFormationWeight;
    
    // Update velocity
    boid.velocity.x += boid.acceleration.x;
    boid.velocity.y += boid.acceleration.y;
    boid.velocity.z += boid.acceleration.z;
    
    // Limit speed
    boid.velocity = limit(boid.velocity, currentMaxSpeed);
    
    // Update position
    boid.position.x += boid.velocity.x;
    boid.position.y += boid.velocity.y;
    boid.position.z += boid.velocity.z;
    
    // Reset acceleration
    boid.acceleration = { x: 0, y: 0, z: 0 };
  }
};
```

One of the most interesting features of our simulation is the ability for boids to form organic shapes. Every few seconds, we generate new organic splines that attract the boids:

### Rendering with Artistic Effects

To create a truly beautiful visualization, we implemented several artistic rendering techniques:

```typescript
const render = () => {
  const canvas = canvasRef.current;
  if (!canvas) return;
  
  const ctx = canvas.getContext("2d");
  if (!ctx) return;
  
  // Apply motion trails if enabled
  if (showTrails) {
    // Create semi-transparent layer over previous frame
    ctx.fillStyle = `rgba(0, 0, 0, ${1 - trailOpacity})`;
    
    if (backgroundColor === "transparent") {
      ctx.globalAlpha = 1 - trailOpacity;
      ctx.clearRect(0, 0, width, height);
      ctx.globalAlpha = 1;
    } else {
      // Create a semi-transparent overlay of the background color
      const bgColor = backgroundColor === "currentColor" ? "black" : backgroundColor;
      let r = 0, g = 0, b = 0;
      
      if (bgColor.startsWith("rgb")) {
        const match = bgColor.match(/rgba?\((\d+),\s*(\d+),\s*(\d+)/);
        if (match) {
          [, r, g, b] = match.map(Number);
        }
      }
      
      ctx.fillStyle = `rgba(${r}, ${g}, ${b}, ${1 - trailOpacity})`;
      ctx.fillRect(0, 0, width, height);
    }
  } else {
    // No trails - clear canvas completely
    if (backgroundColor === "transparent") {
      ctx.clearRect(0, 0, width, height);
    } else {
      ctx.fillStyle = backgroundColor;
      ctx.fillRect(0, 0, width, height);
    }
  }
  
  // Sort boids by z-position for proper depth rendering
  const sortedBoids = [...boidsRef.current].sort((a, b) => b.position.z - a.position.z);
  
  // Create a subtle wave effect through the flock
  const time = Date.now() / 10000;
  
  // Draw each boid with depth cues
  for (const boid of sortedBoids) {
    // Normalized z position (0 to 1) - 0 is closest, 1 is furthest
    const zNormalized = boid.position.z / depth;
    
    // Size based on z - closer boids appear larger
    const sizeScale = 1 - (zNormalized * 0.7);
    const sizeVariation = 0.2 * Math.sin(boid.id * 0.1 + time);
    const displayRadius = boidRadius * sizeScale * (1 + sizeVariation);
    
    // Opacity based on z - closer boids are more opaque
    const baseOpacity = 1 - (zNormalized * 0.6);
    const wavePhase = (boid.position.x / width + boid.position.y / height) * 4;
    const opacityVariation = 0.15 * Math.sin(time * 2 + wavePhase);
    const opacity = Math.max(0.1, Math.min(1, baseOpacity + opacityVariation));
    
    // Set color with opacity and subtle variations
    let fillStyle = boidColor;
    if (boidColor.startsWith('rgb')) {
      fillStyle = boidColor.replace(/rgba?\(([^)]+)\)/, (match, params) => {
        const rgbValues = params.split(',').map((v: string) => v.trim());
        if (rgbValues.length >= 3) {
          // Add slight color variation
          const r = Math.min(255, Math.max(0, parseInt(rgbValues[0]) + Math.floor(sizeVariation * 5)));
          const g = Math.min(255, Math.max(0, parseInt(rgbValues[1]) + Math.floor(sizeVariation * 5)));
          const b = Math.min(255, Math.max(0, parseInt(rgbValues[2]) + Math.floor(sizeVariation * 5)));
          
          return `rgba(${r}, ${g}, ${b}, ${opacity})`;
        }
        return `rgba(${rgbValues[0]}, ${rgbValues[1]}, ${rgbValues[2]}, ${opacity})`;
      });
    } else {
      fillStyle = `rgba(0, 0, 0, ${opacity})`;
    }
    
    // Calculate velocity for elongation
    const velocityMag = magnitude(boid.velocity);
    const velocityNormalized = Math.min(1, velocityMag / currentMaxSpeed);
    
    // Direction of motion
    const direction = {
      x: boid.velocity.x / (velocityMag || 1),
      y: boid.velocity.y / (velocityMag || 1)
    };
    
    // Draw bird-like shapes in direction of movement
    if (velocityMag > 0.1) {
      // Elongated teardrop shape
      const stretchFactor = 1 + velocityNormalized * 0.7;
      
      ctx.beginPath();
      ctx.moveTo(
        boid.position.x - direction.x * displayRadius * stretchFactor,
        boid.position.y - direction.y * displayRadius * stretchFactor
      );
      
      for (let angle = 0; angle < Math.PI * 2; angle += Math.PI / 8) {
        const angleFromDirection = Math.abs(Math.atan2(
          Math.sin(angle), 
          Math.cos(angle) * stretchFactor
        ));
        
        const radiusMultiplier = 0.8 + 0.2 * (1 - Math.cos(angleFromDirection));
        
        ctx.lineTo(
          boid.position.x + Math.cos(angle) * displayRadius * radiusMultiplier,
          boid.position.y + Math.sin(angle) * displayRadius * radiusMultiplier
        );
      }
      
      ctx.closePath();
    } else {
      // Draw circles for slow/non-moving boids
      ctx.beginPath();
      ctx.arc(boid.position.x, boid.position.y, displayRadius, 0, Math.PI * 2);
    }
    
    ctx.fillStyle = fillStyle;
    ctx.fill();
  }
};
```

This rendering approach creates:

1. **Motion trails**: Creates the fluid, smeared appearance characteristic of real starling murmurations
2. **Depth perception**: Boids appear larger and more opaque when closer to the viewer
3. **Natural variations**: Subtle size and color variations give the flock a more organic feel
4. **Bird-like shapes**: Boids elongate in their direction of travel, resembling real birds
